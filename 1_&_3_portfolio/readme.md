# Week 01 & 03 – Online Responsive Resume Website

## 1. Exercise

1. To design and develop an online responsive resume website using HTML and CSS, incorporating semantic HTML elements such as text, hyperlinks, images, lists, tables, and modern layout techniques such as CSS Flexbox or CSS Grid.

2. To design and implement a dark and light theme using JavaScript. The default CSS theme shall be light mode. Implement the theme toggle over the Lab 1 Portfolio Website by directly manipulating DOM elements and their properties or using `classList.toggle()`.

## 2. Concepts

* Semantic HTML elements
* CSS Flexbox and CSS Grid
* JavaScript DOM manipulation
* Dark/Light theme toggle

## 3. Project Structure

```text
1_&_3_portfolio/

├── index.html          # Contains the webpage structure
├── styles.css          # Contains the styling
└── assets/             # Images and other static assets
```
